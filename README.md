# FindBack - Campus Lost & Found System

A desktop app for reporting and finding lost items on campus.

## Features
- Student login and registration
- Report lost and found items with photos
- Search and filter reports
- Image matching to find possible matches
- Email and SMS notification (demo mode)

## How to run
1. Install Python 3.10 or newer
2. Run: python -m pip install customtkinter Pillow
3. Run: python main.py
